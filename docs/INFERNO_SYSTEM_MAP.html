Where it's stuck & what's being done

The bottleneck

The candidate engine is a premium-buy monoculture — ~107 long-premium vs ~0 short-premium, 70/146 straddles — but long-premium is a data-supported KILL. So 85 of 92 paper attempts die at the quality gates. The gate isn't too strict; the pipeline lacks clean candidates. Do not loosen gates.

The fix (in flight)

Codex is rebalancing generation toward the short-premium lead + defined-risk structures and auto-converting cap-busting straddles into cap-fitting spreads (5-wide debit / 1-wide credit / single long leg). Mission "Rebalance candidate generation" = done; follow-on quote-coverage alignment in progress.

Glossary

Promotion gate
The 30 scored operator-paper outcomes (+ distinct events) required before live authority can even be considered. The desk's single binding constraint.
Scored outcome
A paper trade that was staged, filled in paperMoney, closed, and scored by the strategy lab. Only these count toward the 30.
Operator-paper vs Fast sim vs Shadow
Three evidence ledgers. Only operator-paper earns promotion credit; fast sims and shadow replays are research-only (credit OFF) so nothing is double-counted.
Quality gates
The filters a candidate must clear to be stageable: reward/risk ≥ 0.50, complete decision card, premium-hurdle edge, chain liquidity, ticket cap, direction agreement.
Reward/risk floor (0.50)
A debit spread must offer ≥ $0.50 reward per $1 risk. Most current candidates (e.g. 0.05–0.25) fail here.
Premium hurdle
A long-vol setup must have positive forecast edge over the premium it pays. The killed buy-side rarely clears it.
Decision card / paperComparisonAllowed
A candidate's readiness record. If incomplete, it's held in research-watch, not routable.
Classification buckets
stageable-now / operator-routable (ready to approve) · approval-only · research-watch (shadow only) · construction-watch (needs rebuild) · hard-blocked · event-capped.
Authority level
The desk's permission state: halted → paper-evidence-only (now) → (future) live. Live-submit stays hard-locked regardless.
Quote coverage
A bounded, read-only supplemental Schwab option-chain fetch so more candidates can be priced without blowing the 12-symbol tape cap. Built overnight; unblocked pricing.
Cap-fitting fallback
Converting a too-expensive straddle into a defined-risk structure that fits the $500 cap (5-wide debit / 1-wide credit / single long leg).
Premium-buy monoculture
The engine over-producing long-premium (straddle) ideas — the current root cause of the stalled gate.
Buy-side KILL / short-premium lead
Long-premium is a data-supported dead edge; short-premium (selling defined-risk premium) is the promising-but-unproven lead being investigated.
Doctor
./inferno doctor — the full health verdict. Each WARN line becomes a work item. Currently healthy with 1 advisory.
paperMoney
thinkorswim's paper-trading sandbox where you hand-key approved tickets and record fills.
Capture template
The CSV worksheet where you enter real paperMoney fills so an outcome can be scored.
./inferno
The unified control surface. Key verbs: today (approve), status, sync (full refresh), doctor, oauth (Schwab).
Codex / Claude lanes
Ownership boundaries that keep the two AI agents from colliding on shared files; cross-lane work must be flagged and logged.
Coordination (missions/notes)
How the agents hand off: active_missions.json (who owns what) + model_notes.jsonl (what changed). Read on every session start.
