# Decision-First Reporting

## Rule

The default `./inferno status` view answers only the immediate authority,
risk-gate, paper-evidence, research-focus, and live-book questions. Detailed
command catalogs, schedules, and account-planning metrics belong in their
dedicated views or `./inferno status --full`.

## Evidence

On 2026-09-03, the default central report repeated a 29-command catalog and
the full automation schedule alongside its decision state. The concise status
view reduced the persisted central briefing to about 208 estimated tokens.

## Falsifier

Revisit this boundary if an operator cannot identify a hard risk failure, live
authority state, paper-ticket state, promotion gap, or research-versus-ticket
distinction from the default status view.
