# Process trust before throughput

The process review found a distinction not enforced by current promotion
bookkeeping: a counted paper record is not necessarily an independently
verified operator execution. MOD and IREN have intrinsic-estimate outcomes
without recorded fills; DELL has explicit sandbox-seeded notes. All three
count under the present strategy-lab predicate. Agreement with a lineage
report that mirrors the predicate is not independent validation.

The scheduled evidence-goal-loop source still includes `outcome_reviewer
review`, which can close operator-paper rows using the latest stock price
on or after expiration. The operator-only ticket boundary must be enforced
on the call path. No writer was executed for the review and no historical
row was changed. Current open operator-paper count is zero.

Belief: trustworthy provenance and an enforced operator boundary are more
valuable than higher automated record throughput. Repair them before deploying
newly changed schedules or treating sample-clearance projections as progress.

Falsifier: independent paper execution source records reconcile entry, exit,
quantity, time and costs for the counted rows, and a call-path test proves
unattended routines cannot mutate operator ticket state. A label, a seeded
fill-shaped object or a green report does not satisfy this test.

Operational evidence: installed full-sync/nightly script drift; 07:30 briefs
precede the 07:35 market-open refresh; 2/10 full runs accepted under the current
loop evaluator. Its cost-per-point is seconds, not dollars. Those observations
are point-in-time, and this review changes no schedules or strategy thresholds.
